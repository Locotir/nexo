Allow nexo to control this browser?

nexo is a nexo session on this computer. If you allow it, it can:

  • open tabs in a "nexo" tab group and read, click and type in them
  • do that while you are logged in to sites in this browser

Chrome shows "nexo browser started debugging this browser" while it works. Cancel on that bar, or closing this window, stops it. It never touches tabs it did not open, and it does not solve CAPTCHAs or enter passwords or payment details for you.
