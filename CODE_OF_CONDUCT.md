# Code of conduct

Be respectful. Disagree with the idea, not the person. Help newcomers.

Harassment, insults, personal attacks and discrimination are not welcome here, in issues, pull
requests, discussions or anywhere else the project is represented.

To report a problem, use the private **Report a vulnerability** form on the Security tab
or contact a maintainer through their GitHub profile. Reports stay private.

Maintainers may edit or remove comments, commits and issues that break these rules, and may block
people who keep breaking them.
